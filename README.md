# Custom IVR Prompts

Place your recorded `.wav` (16-bit, 8kHz mono, "slin" or "wav49") or `.gsm`
prompt files here. Referenced from `extensions.conf`, e.g.:

- welcome-to-callflow-pro.wav
- press-1-sales-2-support-3-billing.wav
- after-hours-message.wav
- invalid-option.wav
- queue-hold-message.wav
- callback-initiated.wav

Record with a professional voice actor or TTS service, keep tone consistent
across all prompts (same voice for entire IVR tree).
